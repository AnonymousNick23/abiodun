# Abiodun Real Estate

A responsive, front-end real estate website built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Included
- Responsive desktop and mobile layouts
- Sticky navigation and mobile hamburger menu
- Auto-advancing featured property slideshow with 10 properties
- Property grid with category, type, location and price filters
- Load-more interaction (20 sample property listings included; structure supports up to 50)
- Save/favourite heart buttons
- Booking modal with WhatsApp enquiry pre-filled with property description and image URL
- About, contact and footer sections

## WhatsApp booking
The booking links use the supplied number `08164406684`, formatted internationally as `2348164406684`.

## Before publishing
- Replace the sample listings, prices, locations and photos with verified property details.
- Confirm which properties are available for rent or sale.
- Replace sample content with the agency's approved company details.
- Property photos are loaded from Unsplash and require an internet connection.
- WhatsApp opens a pre-filled message; the visitor must press Send.

## Deploy
Upload the extracted folder to GitHub and import the repository into Vercel, or deploy the folder using your preferred static hosting provider.
